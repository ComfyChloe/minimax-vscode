# Support

## Issues

Report bugs and feature requests on the issue tracker of this repository:
<https://github.com/ComfyChloe/minimax-vscode/issues>

When reporting a problem, please include:

- the output of **Output → MiniMax** (it contains the endpoint and the reason for any catalog failure, without credentials),
- your VS Code version (`Help → About`),
- the MiniMax model you were using and the endpoint that was active (`Token Plan · Anthropic API` or `· OpenAI API` in the model picker),
- the API error message, if there was one.

## Questions

- Extension behaviour and configuration: the issue tracker.
- MiniMax API, pricing, Token Plan and model availability: [platform.minimax.io docs](https://platform.minimax.io/docs) and the [MiniMax community](https://platform.minimax.io/).
- The original extension this is based on: [zelosleone/minimax-vscode](https://github.com/zelosleone/minimax-vscode).

## Privacy

The extension only talks to the MiniMax endpoint you configure. The API key is stored in VS Code Secret Storage. No telemetry is collected.
